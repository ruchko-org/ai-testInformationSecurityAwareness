# Information Security Awareness Quiz

Образовательный квиз по информационной безопасности на Flask. За одно прохождение задаётся 30 случайных вопросов из банка, после каждого ответа показывается разбор, а в конце — итоговый результат и работа над ошибками.

## Возможности

- Случайная выборка вопросов на каждое прохождение (`SESSION_SIZE = 30`).
- Разбор каждого ответа: объяснение и пояснение по выбранному варианту.
- После неверного ответа правильный вариант не показывается.
- Итоговая статистика: процент, число верных ответов, разбор ошибок.
- Банк вопросов с категориями и детальными `option_explanations`.

## Требования

- Python 3.10+
- Flask 3.0+

## Установка и запуск

```bash
# клонировать репозиторий
cd ai-testInformationSecurityAwareness

# создать и активировать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# установить зависимости
pip install -r requirements.txt

# запустить приложение
python3 app.py
```

Приложение поднимется на [http://127.0.0.1:5001](http://127.0.0.1:5001).

## Логика работы

| Маршрут | Метод | Назначение |
|---|---|---|
| `/` | GET | Стартовый экран |
| `/start` | GET/POST | Начать прохождение (формируется случайная выборка) |
| `/question` | GET | Показать текущий вопрос |
| `/answer` | POST | Принять ответ и показать разбор |
| `/next` | POST | Перейти к следующему вопросу |
| `/result` | GET | Итог: процент, число верных, разбор ошибок |
| `/restart` | POST | Сбросить сессию и вернуться на главную |

## Формат вопроса

```python
{
    "id": 1,
    "category": "Фишинг",
    "question": "Текст вопроса или практический кейс?",
    "options": ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
    "correct": 2,  # индекс правильного варианта (0..3)
    "explanation": "Общее объяснение в 2-3 предложения.",
    "option_explanations": [
        "Неверно. Почему вариант 0 неправильный. Например: <пример>.",
        "Неверно. Почему вариант 1 неправильный. Например: <пример>.",
        "Верно. Почему вариант 2 правильный. Например: <пример>.",
        "Неверно. Почему вариант 3 неправильный. Например: <пример>."
    ]
}
```

Правила:
- ровно 4 варианта и 4 объяснения;
- ровно одна строка начинается с «Верно.» и её индекс совпадает с `correct`;
- остальные 3 начинаются с «Неверно.» и содержат конкретный пример.

## Добавление вопросов

Дописывайте новые словари в список `QUESTIONS` в `questions.py`, сохраняя уникальность `id` и формата. После добавления удобно проверить целостность:

```bash
PYTHONPATH=. python3 /tmp/validate_quiz.py
```

Валидатор проверяет количество, пропуски и дубли `id`, дубли текстов, распределение `correct` и соответствие «Верно.» индексу правильного ответа.

## Безопасность

`app.secret_key` в `app.py` задан значением-заглушкой. Перед публикацией замените его на случайный секрет (например, через переменную окружения).
